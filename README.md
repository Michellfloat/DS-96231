# React + Vite

Instalar:
```
npm create vite@latest projeto_desejado
```
if yes:<b>Pule tudo abaixo</b>.<br><br>
If no: 
```
cd projeto_desejado
```
Abrir no VSCode
```
code .
```
Instalar Dependencias:
```
npm i ou npm install
```
Executar o projeto(verificar se está tudo certo):

```
npm run dev
```
